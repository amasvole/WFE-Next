# PONG-OVERNIGHT-001

Goal: `Create a playable Pong game with one original twist.`

Executable acceptance: `npm run accept:pong`

Required path: `Goal -> Plan -> START -> disposable workspace -> Build -> Test -> Repair -> Test -> Verify -> DONE -> PLAY`.

Acceptance requires one operator START and no later input; browser-playable Pong; keyboard paddle, opponent, scoring and restart; original moving gravity-well twist; deterministic first-candidate failure followed by bounded repair and retest; verifier PASS; durable memory of goal, plan, decisions, artifacts, checks and outcome.

The deterministic provider proves the kernel loop without external model credentials. Replacing it with a real model adapter is the next integration step and must preserve the structured boundary.
